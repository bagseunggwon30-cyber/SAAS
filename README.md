# PLC 장비·단자대 보관함

제어반 현장 사진 19장에서 읽어 낸 장비(40종)의 종류·제품명·단자번호·쓰임새를 정리한 단일 HTML 도구입니다.
기존 Electron 기반 콘솔 프로젝트는 폐기하고 이 구성으로 새로 시작했습니다.

## 열기

`index.html`을 브라우저로 열면 됩니다. 사진과 크롭 이미지가 파일 안에 들어 있어 인터넷 없이도 동작합니다.
글꼴만 Google Fonts를 쓰며, 오프라인이면 시스템 글꼴로 대체됩니다.

| 화면 | 내용 |
|------|------|
| 장비 도감 | 40종 카드. 분류·검색·"라벨 확인 항목만"·카드/목록 전환. 카드를 펼치면 사양, 단자번호 표, 촬영 사진 링크 |
| 단자대 | TB-A·TB-B·TB-C·소형 단자대·릴레이 터미널의 마킹 플레이트 158점. 분류 강조, 선번 검색, 미결선 단자 표시 |
| 현장 사진 | 사진 19장 기본 탑재. 추가·삭제·메모·확대(←/→). 브라우저 IndexedDB에 자동 저장 |
| 단자 일람표 | 편집 가능한 표(PLC 주소·선번·연결 기기). CSV 내보내기 |

상단 오른쪽에서 테마(시스템/라이트/다크)와 모션 켜기·끄기를 바꿀 수 있고, "보관·내보내기"에서 사진을 내장한 HTML을 다시 내려받을 수 있습니다.

## 판독 기준

- **라벨 확인**: 사진에서 모델명·정격을 직접 읽은 항목
- **추정**: 모양·배선·위치로 판단한 항목
- **미식별**: 라벨이 없어 단정할 수 없는 항목

단자 의미(예: `H`·`LL` 계통, `BP`·`BKN`)는 선번 패턴에서 추정한 것이므로 도면으로 확인해야 합니다.

## 구조와 빌드

```
index.html            빌드 결과 (이미지를 data URI로 내장한 단일 파일)
src/template.html     화면·데이터·로직 원본
src/photos.json       기본 사진 19장의 제목·장비·메모
assets/photos/        현장 사진 (긴 변 1600px)
assets/crops/<id>.jpg 장비 카드용 현장 크롭 (4:3)
assets/products/      제품 공식 사진 (선택)
tools/build.py        위 파일들을 합쳐 index.html 생성
```

```bash
python3 tools/build.py
```

## 제품 사진 추가

`assets/products/<장비id>.jpg` (또는 png·webp)를 넣고 다시 빌드하면 해당 카드에 "현장 / 제품" 전환 버튼이 생깁니다.
장비 id는 `src/template.html`의 `EQUIP` 배열에 있습니다(예: `abs104c`, `mc9b`, `xbm`, `ga700_37`).
빌드 없이 쓰려면 카드를 펼친 뒤 "제품 사진"에서 파일을 고르거나 이미지 주소를 붙여 넣으면 됩니다.
